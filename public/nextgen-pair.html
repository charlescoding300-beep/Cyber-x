Good to know

Quick answers if something doesn’t work.

My code didn’t work.

Codes expire quickly. Request a fresh one, double-check the number matches your WhatsApp account, and type the characters exactly as shown.

Which number do I enter?

The number of the WhatsApp account you want to link, in international format with the country code first and no leading zero.

Is it safe to share the code?

No. Anyone with the code can link a device to your account. Only type it into WhatsApp on your own phone.

Where is Linked devices?

In WhatsApp, open Settings on iPhone or the three-dot menu on Android, then choose Linked devices.
